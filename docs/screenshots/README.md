# Screenshots Gallery

This directory contains all UI screenshots for the Hallucination Detector project.

## Files

- **01-landing-page.png** - Main landing page with claim generation form
- **02-generate-claims.png** - Topic input and claim generation interface
- **03-generated-claims-table.png** - Generated claims displayed in a table
- **04-multi-model-comparison.png** - Side-by-side comparison of 3 NLI models
- **05-aggregated-metrics.png** - Aggregated verification metrics table
- **06-retrieved-evidence.png** - Retrieved evidence table with Retriever Scores

## Usage in README

Screenshots are embedded in the README.md file using markdown image syntax:

```markdown
![Description](docs/screenshots/filename.png)
*Caption text*
```

## Updating Screenshots

To update any screenshot:
1. Run the project: `python app.py`
2. Open browser to `http://localhost:5000`
3. Navigate to the relevant section
4. Take a screenshot using your OS screenshot tool
5. Save to this directory with the appropriate filename
6. Commit and push changes

## Resolution & Format

- **Format**: PNG (lossless)
- **Recommended Resolution**: 1440x900px or higher
- **Color Scheme**: Dark theme (matching UI)
